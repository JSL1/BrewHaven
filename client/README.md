## Brewhaven / client 

BrewHaven is a full-stack coffee ordering application built using the MERN stack. Users can browse menu items, place orders, manage a cart, and save their favorite items and orders.

## Front-end Documentation

# Running the front-end

Open a terminal and run:

```bash
cd client
npm start
```

The /client directory expects a .env file containing:

```bash
ATLAS_URI=my_api_url:my_api_credentials
PORT=5050
SECRETKEY=my_secret_key
```
See ../server for backend implementation.
